Barnyard look options, round two

Three more directions for the dashboard and the three sites that share its shell. They differ from A (Shift Log), B (Switchboard) and C (Run Sheet) in layout, colour, type and wording, and from each other. Each one is built as a theme-able system: it keeps the 18 colour themes, the 18 backgrounds and the density option you have now. Try them in the controls above each mockup. All data is example data.

Light or dark

D. Plain Window

An administrator's tool that looks like one: a list on the left, tables in the middle, a status bar at the bottom. Nothing is decorated. It is built for scanning forty rows quickly, which is what this owner does every day.

Why it fits

The owner reads the same few tables all day: items waiting, services, changes. Rows with fixed columns are faster to scan than tiles, and every column heading says what the column is. State is a word and a shape, so it reads without colour.

What it replaces

Rounded cards, accent rails, hero headline, icon-per-menu-item, the amber default.

Type

The system interface font (Segoe UI Variable on Windows), 13px. Figures are tabular. No download and no webfont.

Icons

None for navigation. State is a word beside one of four shapes: filled circle, triangle, filled square, open circle.

Layout rules

  • Tables and lists only. 1px grid lines, zero radius.
  • Left list for views, with counts. The selected row is tinted and bold, with no rail.
  • A details strip under the selected row replaces any pop-up card.
  • A status bar at the foot carries last refresh and totals.

Themes: how it stays swappable

The whole look is drawn from the site's twelve colour tokens plus the three fixed status colours, so all 18 current themes work unchanged in light and dark. Mapping: page --bg, table surface --panel, header row --panel-2, text --fg and --fg-strong, muted --fg-dim, selection --accent-soft, links --accent, needs-you --attn; up, down and info keep --ok, --alert, --info.

It ships one new theme, Aubergine (grey with a plum accent), as 12 colours in the existing format. Pick it in the controls.

Contrast: the six pairs that themes.test.js already checks pass for Aubergine. Extra pairs this look relies on pass in all 36 theme and mode combinations: muted text on the page (5.0:1 at worst), on the header row (5.2:1), status colours on the panel (5.3:1). One pair does not hold everywhere: muted text on a selected row is 4.46:1 in Dusk dark, so selected rows use main text only.

Backgrounds, density, sidebar

Suits: Plain, Dots, Grid, Ledger and Stripes at Subtle or Medium. The background shows around the window and behind nothing else: tables are opaque, so no text sits on a pattern.

Clashes: Mesh, Aurora, Beams, Rays and Radar at Strong. They stay readable but compete with dense rows at the window's edge.

Density: Compact trims row padding to one pixel; try it in the controls.

Sidebar: there are no icons, so the "icons" option becomes a narrow list with shortened names.

Cost to build

Small to medium. New table, list and status-bar styles in the shared shell; the sidebar becomes a plain list.

E. Poster

The page leads with one sentence about the state of the day, set large, and everything under it is a plain ruled list of lines of type. No tiles, no icons. Size and weight do the work that boxes and badges do elsewhere.

Why it fits

The first question each morning is "what needs me?". A headline sentence answers it before any scanning. Items needing action are set in the needs-you colour; everything fine stays in ink.

What it replaces

Tile grid, number-in-a-box summary, rounded panels, icon rows.

Type

Bricolage Grotesque (already in the site's font folder) at weights 650 to 800 for the headline, item titles and section titles; the system interface font for sentences. Two steps: very large and plain.

Icons

None. Navigation is a line of words; the current view is underlined 3px.

Layout rules

  • Flush left. One column on a phone, two on a desktop.
  • A 3px rule opens the list and 1px rules separate items.
  • Systems and vulnerabilities are written as sentences; the one failing thing is bold in the alert colour.
  • Sentences stay under 55 characters per line.

Themes: how it stays swappable

All 18 current themes work unchanged in light and dark. Mapping: page --bg (the type sits on it, as the current hero does), text --fg and --fg-strong, quiet text --fg-dim, needs-you --attn, the failing phrase --alert, current-view underline --accent, rules --fg-strong and a mix of --fg-dim.

It ships one new theme, Wine (white with a magenta accent; a wine ground in dark). Pick it in the controls.

Contrast: the six tested pairs pass for Wine. Because text sits on the page, E uses only pairs that hold in all 36 combinations: quiet text on the page (5.0:1 worst), needs-you on the page (4.7:1), alert on the page (4.9:1). Accent is not used as text on the page: it falls to 4.38:1 in Amber light, so it only draws the underline.

Backgrounds, density, sidebar

Suits: Plain, Glow, Spotlight, Horizon, Contours and Ripples at Subtle or Medium. The large type sits well on soft light and sparse lines.

Clashes: Stripes, Lattice, Scales, Beams and Grid at Strong. They cross the 15px sentences.

Density: Compact halves the space around each item.

Sidebar: E has no sidebar; the menu is a top line of words. The Sidebar setting would be retired for this look, and the shell would need a one-line top menu.

Cost to build

Medium. A headline sentence, list styles and a sentence-style summary; the menu moves to the top, which touches all four sites. Bricolage is already hosted.

F. Drawing Register

The page is a drawing sheet with a frame, a title block and ruled schedules, the way an engineer lists doors, cables or valves. It treats the dashboard as a register of things with references, states and dates.

Why it fits

An operations owner is keeping a register: items, owners, dates, states. A schedule is exactly that. The title block holds what a reader needs to trust the sheet: when it last synced, which revision, who is signed in.

What it replaces

Cards, big numbers, the sidebar and the glowing dark theme.

Type

IBM Plex Mono (already hosted with the site) for the register, because columns of references and figures align in a fixed-width face; IBM Plex Sans semibold for sheet and schedule titles. Sentence case throughout.

Icons

None. A filled square marks a hold (needs you) or a failure; an open square marks done. Words stay beside the shapes.

Layout rules

  • A double-line frame and a title block at top right with sync time, revision and who is signed in.
  • Every list is a ruled schedule with a title and a reference column.
  • The week is a seven-column strip with a scale along its top edge.
  • No radius, no shadow, no fills except column headers.

Themes: how it stays swappable

All 18 current themes work unchanged in light and dark. Mapping: the sheet is --panel and sits on the page --bg; frame and title-block lines --fg; schedule lines a mix of --fg-dim; header fill --panel-2; today's column --accent-soft; holds --attn; failures --alert.

It ships one new theme, Blueprint: drafting-film blue-grey in light and a deep blueprint blue in dark. Pick it in the controls.

Contrast: the six tested pairs pass for Blueprint. Every pair F uses is on the panel, where the tested pairs already hold. Note that --line measures only 1.2 to 1.4:1 against the panel in every current theme, so F does not rely on it: lines the reader needs use --fg and --fg-dim.

Backgrounds, density, sidebar

Suits: Blueprint, Grid, Ledger, Dots and Contours. The sheet is opaque, so the pattern shows only in the margin around it, like a drafting table.

Clashes: Mesh, Aurora, Glow and Rays. Coloured washes behind a sheet fight the drafting look.

Density: Compact removes the vertical cell padding.

Sidebar: F has no sidebar; the sheets are tabs in a strip. The Sidebar setting would be retired for this look.

Cost to build

Highest of the six. New frame, title block and schedule styles in the shared shell; every page needs a title and a reference column. The fonts are already hosted.

Tests to add to themes.test.js

The test checks six pairs per theme. I ran the extra pairs the new looks use against all 18 themes in light and dark (36 combinations each). All pass except two edge cases, listed. I suggest adding the passing ones as checks so a future theme cannot break a look.

  • Muted text on the page: 5.0:1 at worst. Muted text on the header fill: 5.2:1. Needs-you on the page: 4.7:1. Status colours on the panel: 5.3:1 at worst.
  • Accent as text on the page: 4.38:1 in Amber light, so no look should use it that way. It is fine for marks and underlines.
  • Muted text on a tinted selected row: 4.46:1 in Dusk dark. Selected rows should use main text.
  • The line colour is 1.2 to 1.4:1 on the panel in every theme. It is fine for faint grids, not for rules the reader needs.

Recommendation across all six

Pick D, Plain Window. It is the one built for what this owner does all day: read short tables fast, find the one failing row, and move on. It has no hero, no cards, no icons and no downloaded font, and its state is always a word plus a shape. It keeps every theme, background, density and sidebar option with no change to how they work, and it is cheap to apply to all four sites.

A, Shift Log is the close second and the cheapest. Choose A if you prefer reading to scanning. Choose E if you want the page to feel like yours and are willing to read lines of type instead of scanning rows; it retires the Sidebar setting. F is the most distinctive and the most work, it also retires the Sidebar setting, and its monospace face makes long text harder to read.

Biggest AI tell each new option avoids

DThe identical rounded card with an accent rail and a soft shadow on every block.
EThe big number in a tile with a gradient accent. The headline is a sentence, and the page is not on cream with a serif.
FNeon on near-black, and the tracked-out caps label above every heading. The dark theme is blue, and labels are sentence case.
